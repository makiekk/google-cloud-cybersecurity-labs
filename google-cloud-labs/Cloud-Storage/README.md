# Lab 6 – Cloud Storage Security

## Building on Previous Work

**From Lab 1 (VPC):** I built secure network infrastructure.

**From Lab 2 (SCC):** I monitored resources and remediated security issues (including a publicly accessible bucket).

**From Lab 3 (Organization Policies):** I enforced organization-wide security policies.

**From Lab 4 (IAM):** I implemented fine-grained access controls.

**From Lab 5 (Assured Workloads):** I ensured infrastructure meets compliance requirements.

**In this lab:** I secure data at rest through Cloud Storage security best practices. Building on all previous security layers, I now implement encryption, access controls, audit logging, and data lifecycle policies to protect sensitive data stored in Cloud Storage.

## Objective

Learn how to secure Google Cloud Storage through encryption, access controls, uniform bucket-level access, and audit logging to protect data at rest and ensure compliance with data security regulations.

## Security Progression Summary

This lab series demonstrates a complete cloud security journey:

1. **Infrastructure Security:** Design secure networks and resources (VPC)
2. **Detective Controls:** Monitor and detect security issues (SCC)
3. **Preventive Controls:** Enforce policies to prevent misconfigurations (Organization Policies)
4. **Access Control:** Implement principle of least privilege (IAM)
5. **Compliance:** Ensure regulatory requirements are met (Assured Workloads)
6. **Data Protection:** Secure sensitive data at rest and in transit (Cloud Storage Security)
